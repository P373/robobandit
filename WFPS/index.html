How we built it

The proposal

How the website is run today, and going forward

Today

  • A WordPress site, hosted and maintained by an outside company that we pay.
  • Updates mean logging into WordPress or asking the vendor, so pages fall out of date. The tuition page and fundraiser still refer to 2024–2025.
  • WordPress needs regular plugin and security updates to stay safe.

Going forward

  • GitHub stores the website and saves every change, so we can see who changed what and undo anything in one step.
  • Cloudflare Pages hosts it for free, with security, HTTPS and fast loading built in. No plugins and no database to hack.
  • The board owns every account, so nothing depends on one vendor or one volunteer.

Updating the site by talking to AI

The board shares one AI account. Anyone on the board can describe a change in plain English, and the AI makes it.

Ask

"Post the 2026–27 tuition rates and the registration dates."

AI makes the change

It edits the pages, keeping the design consistent.

Preview on staging

The change appears on a private staging site first, for the board to check.

Ship it

When it looks right, it goes live on westfalmouthpreschool.org.
