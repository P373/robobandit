# 5th grade

Educational games and materials for 5th graders.

Each game goes in its own folder here (for example `5th-grade/fractions/index.html`), so it's served at
`robobandit.com/5th-grade/<name>/`. From a page in that folder, shared files are one level further up than
from the root games: use `../../common.js`, `../../common.css`, `../../touch-stick.js` and `../../vendor/three.min.js`.
